## About GPT-Live Voice Canvas

GPT-Live Voice Canvas is a browser-based visual layer for live voice AI interactions. It focuses on turning real-time conversation signals into a canvas-driven display, making the flow of interaction easier to follow during demos, experiments, or presentations.

The project is built around a simple web interface, so it can be opened and used in standard browsers without a desktop install. It is a good fit for creators, developers, and teams who want a lightweight way to present or inspect voice AI activity in motion.
